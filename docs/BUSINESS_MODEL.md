# Modèle Économique — FamilyXP / FamQuest

## 💰 Modèle Freemium

### Version Gratuite

- 1 ou 2 foyers
- Nombre limité de membres
- Règles simples
- Historique limité (30 jours)
- Récompenses simples

### Version Premium

- Foyers illimités
- Membres illimités
- Statistiques avancées
- Historique complet
- Contrats multiples simultanés
- IA d'aide à la création de contrats
- Exports PDF
- Personnalisation (thèmes, badges)
- Récompenses avancées

## 💵 Prix envisagé

- **Mensuel :** 5 à 10 €/mois par famille
- **Annuel :** 50 à 80 €/an (économie de ~2 mois)

## 🎯 Déclencheurs Premium

Le passage au Premium est naturel quand la famille dépasse le modèle simple :

- Plusieurs foyers (garde alternée, grands-parents)
- Statistiques avancées souhaitées
- Besoin d'IA pour créer des contrats
- Export PDF pour impression/archivage

## 📊 Marché

### Cœur de cible

- Parents 30-50 ans
- Familles recomposées
- Garde alternée
- Grands-parents impliqués

### Taille estimée

- En France : ~1 million de familles recomposées
- Extension possible : colocations, clubs, associations, écoles

## 🏗 Structure des coûts

### Coûts fixes mensuels

| Poste | Coût |
|-------|------|
| GitHub Copilot Pro (David + Docdadi) | ~20 $ |
| Firebase Spark (départ) | Gratuit |
| Firebase Blaze (après croissance) | Pay-as-you-go |
| Nom de domaine | ~10 €/an |

### Coûts de développement

- Temps : David + Docdadi (soirées/week-ends)
- Outils : GitHub Free, Firebase Spark

## 📈 Métriques clés

- **Activation :** Création du premier contrat
- **Rétention :** Utilisation quotidienne (ajout de points)
- **Viralité :** Invitation d'autres foyers (grands-parents)
- **Monétisation :** Passage Premium après X foyers

## 🔮 Vision long terme

1. **MVP** — Gratuit, tester le concept avec notre famille
2. **Croissance** — Bouche-à-oreille, familles recomposées
3. **Monétisation** — Premium pour fonctionnalités avancées
4. **Extension** — Colocations, clubs, associations, écoles
